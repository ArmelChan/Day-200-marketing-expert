# Day-200 Marketing Expert

> 一套完整的市場營銷操作系統，涵蓋 18 個核心模組，由產品分析到輸出交付及優化計劃，適合初學者到高階策略師使用

## 這個 Repo 是什麼？

這不是一個工具或軟件。這是一套**結構化的市場營銷思維框架**，將市場營銷工作拆解成 18 個可獨立執行、亦可串連使用的模組。每個模組對應真實工作場景中的一個核心職能。

設計邏輯：從了解產品開始，經過市場研究、策略制定、創意執行，到最終輸出可交付成果並持續優化，形成一個完整的工作閉環。

## 00 — MARKETING_OS_ROUTER

### 是什麼？

這是整個系統的入口。它的作用類似一個決策樹：根據你當前的任務類型，指引你進入正確的模組，避免在錯誤的框架上浪費時間。

### 初學者理解

想像你走進一家醫院，你不會直接去找醫生，而是先去接待處，告訴他們你的問題，接待員再指引你去正確的科室。MARKETING_OS_ROUTER 就是那個接待處。

### 中階理解：使用邏輯

Router 的核心問題是：**你現在要解決的是什麼類型的問題？**

| 問題類型 | 對應模組 |
|---|---|
| 我有一個產品，但不知道如何定位 | 02 PRODUCT_ANALYSIS |
| 我想了解競爭對手在做什麼 | 05 COMPETITOR_INTELLIGENCE |
| 我要策劃一個推廣活動 | 06 CAMPAIGN_STRATEGY |
| 我需要寫文案或設計主視覺 | 07 CREATIVE_COPY_KV |
| 我要找 KOL 合作 | 11 KOL_COLLABORATION |
| 我要向管理層匯報市場狀況 | 15 MARKETING_INTELLIGENCE |

### 高階理解：Router 作為工作流編排

對於管理多個品牌或多個項目的市場營銷負責人，Router 可以作為工作流編排工具。每個模組有明確的輸入和輸出格式，可以串連成一個自動化的工作流，例如：

PRODUCT_ANALYSIS → COMPETITOR_INTELLIGENCE → CAMPAIGN_STRATEGY → CREATIVE_COPY_KV → OUTPUT_ARTIFACTS

這個串連邏輯確保策略建立在產品理解和競爭分析之上，而非憑空創意。

## 02 — PRODUCT_ANALYSIS

### 是什麼？

產品分析是所有市場營銷工作的起點。在寫任何文案、設計任何視覺、策劃任何活動之前，你必須先透彻理解你正在推廣的產品。

### 初學者理解：五個基本問題

對任何產品，先回答以下五個問題：

1. 這個產品解決什麼問題？
2. 誰最需要這個產品？
3. 它和市場上其他類似產品有什麼不同？
4. 消費者為什麼要現在買，而不是以後買？
5. 消費者在哪裡會遇到這個產品？

### 中階理解：產品分析框架

**功能層面分析：**
- 核心功能：產品的主要用途是什麼？
- 輔助功能：有哪些附加價值？
- 使用場景：消費者在什麼情況下使用？

**市場層面分析：**
- 目標受眾畫像：年齡、性別、收入、生活習慣、媒體消費習慣
- 購買動機：功能需求、情感需求、社交需求
- 購買障礙：價格、認知不足、使用門櫃、競品忠誠度

**競爭層面分析：**
- 直接競品：同類產品中的主要競爭者
- 間接競品：解決相同問題的不同方式
- 潛在競品：可能進入這個市場的新玩家

### 高階理解：Jobs-to-be-Done 框架

高階產品分析不只是描述產品特性，而是理解消費者「雇用」這個產品來完成什麼任務。

Jobs-to-be-Done（JTBD）框架的核心問題：消費者購買這個產品，真正想要完成的是什麼？

例如：消費者購買一支美白精華，表面上是要「美白」，但深層次的 Job 可能是「在重要場合前快速改善膚色，增強自信」。這個理解會直接影響文案方向、KOL 選擇和投放時機。

## 03 — INGREDIENT_TO_MARKET

### 是什麼？

這個模組處理的是「成分導向」的產品，特別適用於美妙、保健品、食品等以成分為核心賣點的品類。它解決的問題是：如何將技術性的成分資訊，轉化為消費者能理解和感興趣的市場語言？

### 初學者理解

消費者不會因為「含有 5% 煙酰胺」而購買產品。他們購買的是「淡化色斑、均勻膚色」。INGREDIENT_TO_MARKET 的工作就是建立這個翻譯橋樑。

### 中階理解：成分轉化三步法

**第一步：成分功能確認**
- 這個成分在科學上被證實有什麼功效？
- 有效濃度是多少？產品中的含量是否達到有效濃度？
- 有沒有相關的臨床研究或第三方認證？

**第二步：消費者語言轉化**
- 這個功效對消費者的日常生活意味著什麼？
- 用消費者會用的詞彙來描述，而非化學术語
- 找到一個具體的使用場景讓消費者產生畫面感

**第三步：差異化定位**
- 市場上有多少產品含有相同成分？
- 我們的濃度、配方、來源有什麼独特之處？
- 這個独特性是否足以構成購買理由？

### 高階理解：成分故事化策略

高階的成分營銷不只是功能描述，而是建立成分的品牌故事。例如：

- 成分來源故事：某成分來自特定地區的稀有植物，有独特的生長環境
- 科研故事：品牌投入多少研發資源，與哪些研究機構合作
- 濃度優勢故事：在相同成分下，我們的濃度是市場平均的幾倍

這些故事可以成為 KOL 合作、社交媒體內容和 PR 稿的核心素材。

## 04 — NEW_PRODUCT_DEVELOPMENT

### 是什麼？

新產品開發模組處理的是從市場機會識別到產品上市準備的完整流程。它不只是產品研發，而是從市場營銷角度參與產品開發決策。

### 初學者理解：新產品開發的五個階段

1. **機會識別**：市場上有什麼未被滿足的需求？
2. **概念開發**：我們可以用什麼產品來滿足這個需求？
3. **可行性評估**：這個產品在技術、成本、法規上是否可行？
4. **開發與測試**：產品原型開發，消費者測試
5. **上市準備**：定價、包裝、渠道、推廣策略

### 中階理解：市場營銷在 NPD 中的角色

市場營銷團隊在 NPD 過程中的核心貢獻：

- **消費者洞察輸入**：將市場研究和消費者反饋帶入產品定義階段
- **競品分析**：確保新產品有明確的差異化定位
- **命名與包裝方向**：在產品開發後期參與命名和包裝設計決策
- **上市策略**：提前規劃產品上市的推廣節奏和渠道策略

### 高階理解：Stage-Gate 流程與市場驗證

高階 NPD 管理通常採用 Stage-Gate 流程，在每個階段之間設置「閘口」，只有通過評審才能進入下一階段。市場營銷團隊在每個閘口的核心評審維度：

| 閘口 | 市場營銷評審重點 |
|---|---|
| Gate 1（概念篩選） | 市場規模是否足夠大？目標受眾是否清晰？ |
| Gate 2（商業評估） | 定價空間是否支持盈利？競爭壁壘是否可建立？ |
| Gate 3（開發） | 消費者測試反饋是否支持繼續投入？ |
| Gate 4（上市準備） | 渠道接受度如何？首批訂單是否確認？ |

## 05 — COMPETITOR_INTELLIGENCE

### 是什麼？

競爭對手情報是系統性地收集、分析和應用競爭對手資訊的過程。它的目的不是拄袲，而是理解市場格局，找到自己的差異化空間。

### 初學者理解：競爭分析的基本步驟

1. 列出你的三個主要競爭對手
2. 分別記錄他們的產品特點、價格、主要銷售渠道
3. 找出他們的強項和弱項
4. 思考：我們在哪些方面可以做得更好？

### 中階理解：系統化競爭情報框架

**定義競爭範圍：**
- 「追蹤名單」：5 至 8 個你經常直接競爭的對手
- 「觀察名單」：10 至 15 個間接競爭者或新興玩家

**分析維度：**
- 產品：功能、規格、包裝、定價
- 定位：品牌訊息、目標受眾、差異化主張
- GTM 策略：渠道、推廣方式、KOL 合作
- 動能：社交媒體增長、新品推出頻率、市場份額變化

**更新頻率：**
- 每週 30 分鐘：快速掃描社交媒體和新聞
- 每月 2 至 3 小時：更新競爭對手檔案
- 每季度半天：深度分析和策略調整

### 高階理解：競爭情報的戰略應用

高階競爭情報不只是收集資訊，而是建立預測能力。核心問題包括：

- 競爭對手下一步可能做什麼？（基於他們的招聘、投資、專利申請）
- 哪些競爭對手正在失去市場份額，為什麼？
- 市場上有哪些「空白地帶」是所有競爭對手都沒有覆蓋的？

競爭情報的最終輸出應該是具體的戰略建議，而非資訊堆砌。

## 06 — CAMPAIGN_STRATEGY

### 是什麼？

活動策略是將品牌目標轉化為具體的市場活動計劃的過程。它回答的核心問題是：我們要在什麼時間、通過什麼渠道、向什麼人、傳達什麼訊息、達到什麼效果？

### 初學者理解：活動策略的六個要素

任何市場活動都需要明確以下六個要素：

1. **目標**：這次活動要達到什麼？（品牌知名度、銷量、新客戶獲取）
2. **受眾**：我們要觸達誰？
3. **訊息**：我們要說什麼？
4. **渠道**：我們在哪裡說？
5. **時間**：我們什麼時候說？
6. **預算**：我們有多少資源？

### 中階理解：活動策略框架

**目標設定（SMART 原則）：**
- Specific：具體，例如「提升品牌知名度」太模糊，「在目標受眾中將品牌認知度從 35% 提升至 45%」才是具體
- Measurable：可衡量
- Achievable：可實現
- Relevant：與業務目標相關
- Time-bound：有時間限制

**渠道選擇邏輯：**
- 受眾在哪裡，渠道就在哪裡
- 不同渠道有不同的內容形式和互動方式
- 預算分配應基於渠道的預期 ROI，而非平均分配

**訊息架構：**
- 核心訊息：一句話概括這次活動要傳達的最重要信息
- 支持訊息：2 至 3 個支持核心訊息的具體論點
- 行動呼叱：明確告訴受眾接下來要做什麼

### 高階理解：整合營銷傳播（IMC）

高階活動策略追求整合營銷傳播效果，即所有渠道和接觸點傳達一致的品牌訊息，形成協同效應。

IMC 的核心原則：

- 同一個核心訊息，在不同渠道用不同的方式表達
- 線上和線下活動互相引流
- 付費媒體、自有媒體和贏得媒體（earned media）的協同規劃
