# Skill Name / ID

Hong Kong Social Content Generator
ID: 09_SOCIAL_CONTENT

## Purpose

將 Campaign、Brand、Product 或 Business Message 轉化成符合香港平台文化嘅 Social-first Content。

## Trigger Condition

當要求：

- Social Post
- Facebook Post
- Instagram
- Threads
- Content Calendar
- Caption
- Reels Copy
- Social Campaign

## Required Input Fields

最低：

- Brand
- Topic / Product
- Objective

建議：

- Platform
- Audience
- Key Message
- CTA
- Visual
- Campaign
- Tone
- Posting Period
- Offer

## Step-by-Step Reasoning Workflow

1. 定義每篇 Post 嘅單一 Objective。
2. 找出 Audience Trigger。
3. 選擇 Content Angle。
4. 建立 Hook。
5. 將 Product Value 融入生活情境。
6. 調整 Platform-specific Structure。
7. 建立 CTA。
8. 配合 Suggested Visual。
9. 檢查 Hong Kong Tone。
10. 建立 Variations / Testing Options。

## Hong Kong Native Tone Rules

Instagram：
- Lifestyle
- 簡潔
- 有畫面

Facebook：
- 清楚
- 資訊完整
- 易 Scan

Threads：
- 似真人開話題
- 避免企業公告腔

WhatsApp：
- 短
- 直接
- 有禮貌

全面避免：

- 翻譯腔
- 「用戶」
- 「賦能」
- 「種草」
- 「爆款」
- 「全網」
- 過多 Emoji
- AI 式「不只是…更是…」濫用

## Quality Self-Check

- [ ] 每篇有單一 Objective？
- [ ] Opening 是否夠快？
- [ ] 是否貼近香港生活？
- [ ] 是否只講產品功能？
- [ ] CTA 是否自然？
- [ ] Visual 是否配合 Copy？
- [ ] Platform Tone 是否不同？
- [ ] 有冇過度 Sell？
- [ ] Claims 是否 safe？
- [ ] 是否可以直接 Publish？
