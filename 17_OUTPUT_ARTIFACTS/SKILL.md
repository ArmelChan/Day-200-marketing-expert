# Skill Name / ID

Output & Artifact Formatter
ID: 17_OUTPUT_ARTIFACTS

## Purpose

將所有 Marketing OS 結果轉化為可直接分享、貼入工作工具、匯入 Spreadsheet 或建立簡報嘅標準化 Deliverables。

## Trigger Condition

所有 Skills 完成主要分析後都應進入本 Skill。

亦可由用家直接觸發：

- 生成附件
- 轉 Markdown
- CSV-ready
- PPT
- Brief
- Meeting Minutes
- Action Tracker
- Report
- Template

## Required Input Fields

最低：

- Source Content
- Desired Artifact Type

可選：

- Audience
- File Name
- Presentation Length
- Table Fields
- Owner
- Deadline
- Branding
- Confidentiality

## Step-by-Step Reasoning Workflow

1. 確認 Artifact 嘅使用者及使用場景。
2. 選擇最適合格式。
3. 移除分析過程中不需要對外展示嘅內容。
4. 保留 Decision、Evidence、Action。
5. 統一 Terminology。
6. 建立標題、Section、Table Hierarchy。
7. 按需要建立 CSV-ready / Markdown / Slide Structure。
8. 檢查 Missing Fields。
9. 檢查 Confidentiality。
10. 完成 Usability QA。
11. 提供附件清單及 Suggested Filename。
