# Skill Name / ID

Product Deep Analysis
ID: 02_PRODUCT_ANALYSIS

## Purpose

由產品資料出發，分析產品定位、Feature、Benefit、Consumer Value、競爭力、市場機會及 Marketing Action。

## Trigger Condition

當用家要求：

- 指定產品分析
- Product Positioning
- Selling Points
- Product SWOT
- Product USP
- Feature / Benefit Analysis
- Market Opportunity
- Marketing Recommendation

## Required Input Fields

最低：

- Product Name
- Product Information 或 Product URL

建議：

- Brand
- Ingredients / Features
- Price
- Product Format
- Market
- Target Audience
- Distribution
- Competitors
- Supporting Evidence

## Step-by-Step Reasoning Workflow

1. 建立 Product Snapshot，只記錄已知事實。
2. 拆解 Features、Ingredients、Technology、Format。
3. 建立 Feature → Benefit → Customer Value。
4. 判斷核心 Consumer Job-to-be-Done。
5. 建立 Target Audience Hypothesis。
6. 分析直接及間接競爭替代方案。
7. 找出產品可 defend 嘅 Differentiation。
8. 完成 SWOT。
9. 建立 Marketing / Sales Opportunity。
10. 排出短、中、長期 Action Priority。

## Hong Kong Native Tone Rules

Consumer-facing examples：

- 香港繁體中文
- 用香港消費者容易理解嘅 Benefit Language
- 不將科研術語直接翻譯成廣告句
- 避免過度 Promise
- 健康產品以「有助、支持、維持」等合適方式表述，並以實際證據為準

## Quality Self-Check

- [ ] 有冇將 Feature 當 USP？
- [ ] Benefit 是否對消費者有意義？
- [ ] Selling Point 是否有證據？
- [ ] 是否考慮競爭替代品？
- [ ] SWOT 是否產品-specific？
- [ ] 是否符合 Brand Positioning？
- [ ] 商業建議是否可落地？
- [ ] Fact / Insight / Recommendation 是否清楚？
- [ ] 有冇誇大健康功效？
- [ ] 香港市場語境是否自然？
