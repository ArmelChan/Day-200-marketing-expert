# Skill Name / ID

Creative Copy & KV Messaging
ID: 07_CREATIVE_COPY_KV

## Purpose

將 Campaign Strategy、KV Image Reference 及 Brand Tone 轉化成 Tagline、Headline、Sub-headline、CTA 及 Visual Copy System。

## Trigger Condition

當要求：

- Tagline
- KV Copy
- Headline
- Advertising Copy
- Campaign Copy
- Visual Copy
- Banner Copy
- POSM Headline

## Required Input Fields

最低：

- Campaign Context
- Brand Context
- Product / Key Message

建議：

- KV Image
- Celebrity
- Target Audience
- Campaign Big Idea
- Desired Tone
- Key Claims
- CTA
- Channel

## Step-by-Step Reasoning Workflow

1. 提取 Campaign 核心一句。
2. 分析 KV 畫面真正傳達嘅情緒。
3. 定義 Copy 要補充畫面定重複畫面。
4. 建立 Brand-led、Emotion-led、Benefit-led Routes。
5. 產出 Shortlist。
6. 檢查香港語感及讀音節奏。
7. 檢查 Claims / Legal Risk。
8. 評估記憶度與 Brand Ownership。
9. 選出推薦版本。
10. Adapt 至不同 Media。

### Recommendation

## Hong Kong Native Tone Rules

- Tagline 要講得出口
- 避免翻譯句式
- 避免為押韻而犧牲自然度
- 廣東話與書面語比例按 Brand 決定
- 不用內地 Marketing Buzzwords
- Wellness / Premium Brand 保持簡潔、有質感
