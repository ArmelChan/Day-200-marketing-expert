基本流程：

User Request
→ Router
→ Domain Skill
→ Supporting Skill(s)
→ Output Artifact
→ Final QA

## Common Operating Rules

所有 Skills 共同遵守：

1. Evidence Before Assumption
2. Fact / Insight / Recommendation 分層
3. Consumer Before Product
4. Brand Consistency
5. Commercial Viability
6. Hong Kong Market First
7. Hong Kong Native Tone
8. Health Claims 必須 Evidence-based
9. Current Market Data 需要 Research
10. Deliver Action，不只 Deliver Idea

## Default Language

Secondary:
English for established professional terminology
