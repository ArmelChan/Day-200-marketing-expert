# Skill Name / ID

Brand Design & Art Direction
ID: 08_DESIGN_DIRECTION

## Purpose

在固定 Brand Design System 之上，按每次 Task-specific Creative Style 建立可供 Designer 或 AI Image Tool 執行嘅 Art Direction。

## Trigger Condition

當要求：

- Design
- KV Design
- Visual Direction
- Canva Brief
- POSM Design
- Social Visual
- Packaging Direction
- AI Image Prompt
- 每次有指定 Design Style

## Required Input Fields

最低：

- Brand
- Design Task
- Deliverable
- Specific Creative Style

建議：

- Brand Guideline
- Logo
- Colour
- Font
- Visual Reference
- Campaign Copy
- Product Image
- Audience
- Media Size
- Mandatory Elements

## Step-by-Step Reasoning Workflow

1. 分清固定 Brand Codes 同本次 Creative Style。
2. 定義設計目的：Awareness / Education / Conversion。
3. 分析 Reference 只取原則，不直接複製。
4. 建立 Visual Hierarchy。
5. 定義 Colour、Typography、Composition、Lighting。
6. 定義 Product / Talent / Copy Placement。
7. Adapt 各 Media Ratio。
8. 建立 AI Image Prompt 如需要。
9. 檢查 Brand Recognition。
10. 完成 Production QA。
