# Day-200 Marketing Expert

> 中英對照版 / Bilingual Version (Chinese / English)

> 一套完整的市場營銷操作系統，涵蓋 17 個核心模組，由產品分析到輸出交付，適合初學者到高階策略師使用。
>
> A complete marketing operating system covering 17 core modules,
> from product analysis to final output delivery, suitable for
> beginners to advanced strategists.

---

## 這個 Repo 是什麼？ / What is this Repo?

**[中文]**
這不是一個工具或軟件。這是一套**結構化的市場營銷思維框架**，將市場營銷工作拆解成 17 個可独立執行、亦可串連使用的模組。每個模組對應真實工作場景中的一個核心職能。

設計邏輯：從了解產品開始，經過市場研究、策略制定、創意執行，到最終輸出可交付成果，形成一個完整的工作閉環。

**[English]**
This is not a tool or software. It is a **structured marketing
thinking framework** that breaks down marketing work into 17
modules that can be executed independently or chained together.
Each module corresponds to a core function in real-world work
scenarios.

Design logic: Starting from understanding the product, through
market research, strategy formulation, creative execution, to
final deliverable output — forming a complete workflow loop.

## 如何使用這個 Repo / How to Use this Repo

**[中文]**
- **初學者**：從 00 ROUTER 開始，根據當前任務找到對應模組，閱讀「初學者理解」部分，完成基本練習。
- **中階用戶**：深入閱讀每個模組的「中階理解」部分，嘗試將框架應用到實際工作中。
- **高階用戶**：重點閱讀「高階理解」部分，建立可持續的知識管理系統。

**[English]**
- **Beginners**: Start with 00 ROUTER, find the corresponding
  module for your current task, read the "Beginner Understanding"
  section, and complete basic exercises.
- **Intermediate Users**: Dive into the "Intermediate
  Understanding" section of each module, apply frameworks to
  actual work.
- **Advanced Users**: Focus on the "Advanced Understanding"
  section, build a sustainable knowledge management system.
