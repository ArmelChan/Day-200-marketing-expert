# Skill Name / ID

KOL Collaboration & Experience Storytelling
ID: 11_KOL_COLLABORATION

## Purpose

建立以「真實生活體感」為核心嘅 KOL Collaboration Brief，令產品自然融入創作者故事，而唔係變成背稿式廣告。

## Trigger Condition

當要求：

- KOL Brief
- Influencer Collaboration
- Creator Brief
- 體感分享
- Trial Experience
- KOL Script Direction

## Required Input Fields

最低：

- Brand
- Product
- Campaign Objective

建議：

- KOL Name / Type
- Audience
- Product Features
- Permitted Claims
- Campaign Angle
- Deliverables
- Timeline
- Usage Rights
- Mandatory Mention
- Do / Don't

## Step-by-Step Reasoning Workflow

1. 定義 KOL 喺 Campaign 嘅角色。
2. 找出 Audience 最容易感受嘅 Daily Pain Point。
3. 將 Benefit 轉成 Body Feel / Daily Experience Territory。
4. 建立 Before → Discovery → Experience → Change。
5. 設計自然 Hook。
6. 建立 KOL Freedom Zone 與 Mandatory Message。
7. 設計 Deliverables。
8. 檢查 Claims 與真實體驗界線。
9. 建立 CTA。
10. 完成 Brand & Authenticity QA。

## Hong Kong Native Tone Rules

- KOL 講法要似本人
- 不要品牌幫 KOL 寫到太完整逐字稿
- 生活情境以香港日常為主
- 避免「用了 X 天人生完全不同」
- 體感應具體但不誇張
- 健康產品 Personal Experience 不能被寫成 Universal Claim

## Quality Self-Check

- [ ] 故事先定產品先？
- [ ] 體感是否容易理解？
- [ ] KOL 是否有發揮空間？
- [ ] Mandatory Message 是否太多？
- [ ] Claims 是否安全？

- [ ] Product Integration 是否自然？

- [ ] 是否符合 HK Tone？
