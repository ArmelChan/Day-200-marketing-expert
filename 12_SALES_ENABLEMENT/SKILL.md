# Skill Name / ID

Hong Kong Sales Enablement
ID: 12_SALES_ENABLEMENT

## Purpose

將產品 Feature 轉成香港客人真正理解嘅 Value Proposition、Sales Script、FAQ、Objection Handling 及 CTA。

## Trigger Condition

當要求：

- Sales Script
- Value Proposition
- Retail Talking Points
- Objection Handling
- FAQ
- Product Pitch
- WhatsApp Selling
- Promoter Script

## Required Input Fields

最低：

- Product
- Product Features

建議：

- Brand Positioning
- Audience
- Key Benefits
- Evidence
- Price
- Competitors
- Channel
- Common Objections

## Step-by-Step Reasoning Workflow

1. 抽取 Feature。
2. 轉成 Functional Benefit。
3. 轉成 Customer Value。
4. 按 Audience 分出不同 Buying Motivation。
5. 為每組建立一句 Value Proposition。
6. 建立 30-sec / 60-sec Script。
7. 建立 Common Objections。
8. 用 Proof / Reframing 回應。
9. 建立 Channel-specific CTA。
10. 檢查 Sales Tone 與 Claims。

## Hong Kong Native Tone Rules

- Promoter Script 要講得出口
- 唔使用 Marketing jargon
- 唔用「親、下單、入手、種草」
- 不過度熱情
- 香港 Retail Tone：專業、自然、有少少人情味
- Sales 不應讀產品說明書

## Quality Self-Check

- [ ] Value 是否先於 Feature？
- [ ] 客人聽完知唔知「關我咩事」？
- [ ] Script 是否自然？
- [ ] Evidence 是否可靠？
- [ ] 是否避免過度 Claim？
- [ ] Objection 有冇正面處理？
- [ ] 是否按 Audience 分化？
- [ ] CTA 是否合理？
- [ ] 是否符合 Channel？
- [ ] Sales 可否直接使用？
